Theme: From CampusPress to HTML/CSS to GitHub Pages

Task Review: What I Did and How It Went The goal of this workshop was to start creating content and publishing it online, laying the foundation for a personal portfolio that I will keep updating. In class, we engaged with three different website-building practices: a. Using a content management system: I activated and familiarised myself with the University of Leeds’ CampusPress site. b. b. Building web pages with code: I downloaded VS Code, a code editor, and used it to write my HTML and CSS files. c. Hosting and publishing publicly: I created a GitHub account, uploaded the code to GitHub and made it publicly accessible through GitHub Pages. CampusPress is a ready-made platform that allows users to choose a template, customise the design and add content without writing any code. HTML/CSS, by contrast, required me to write the code myself, which gave me full control over everything from layout to responsive design. It is highly flexible. GitHub Pages was the most “magical” step. I created a repository, uploaded index.html and stylesheet.css, enabled Pages in the settings, and a public link was generated. I think of it as a “bridge” between my local files and the public web. Connections and Revelations a.Week1:
